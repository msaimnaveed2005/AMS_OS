Welcome to AMS OS, a university project operating system simulator built with C++ and GTK3. AMS OS is designed to provide a user-friendly and interactive environment for learning about operating system concepts. With a range of built-in applications and tools, AMS OS allows users to explore and experiment with various aspects of operating systems, including process management, memory management, and file systems. Whether you're a student or simply interested in learning more about operating systems, AMS OS is the perfect platform for you.
